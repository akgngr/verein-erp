## Expansion rules

Only `header.right` is accepted for runtime mounting. Other names in the type union are reserved and require a separate responsive size/overflow policy, authorization review, accessibility test and network budget before use. Adding a module widget does not grant data access. Do not scan the filesystem at runtime, use import paths from user preferences, or put personal/association data in logs or external calls.

The earlier plan to mount the notification bell directly in the header was superseded by its registered module widget. `#369`/`#378` are historical implementation inputs, not a second bell implementation.
